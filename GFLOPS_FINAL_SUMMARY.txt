KEY FINDINGS


✓ CTM internal loop is extremely lightweight
  ~2.8 MFLOPs per iteration (same regardless of backbone)

✓ Backbone feature extraction dominates computation
  • 99.98% of first-iteration FLOPs (with 224×224 input)
  • 99.0% of total FLOPs over 50 iterations

✓ The "per loop" is identical with or without backbone
  Backbone runs ONCE per forward pass (not per iteration)
  Each CTM iteration adds ~2.79 MFLOPs in all cases

✓ CTM is an efficient reasoning layer
  • Adds only 0.14 GFLOPs for 50 iterations vs 13.74 GFLOPs for backbone
  • Enables multi-step iterative reasoning with minimal overhead
  • Scales linearly with number of iterations

✓ Input size has quadratic impact on backbone FLOPs
  • 112×112: backbone = 3.43 GFLOPs, total = 3.57 GFLOPs
  • 224×224: backbone = 13.74 GFLOPs, total = 13.88 GFLOPs
  • 4× difference (spatial dimensions scale as h×w)
